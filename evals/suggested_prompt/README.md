# Suggested-prompt dev sets

`devset.jsonl` is generated by `uv run python -m decafclaw.survey devset`
and is **git-ignored**. It contains raw transcript text from conversation
archives, which may be private. Regenerate it on the machine that holds the
corpus; never commit or attach it to a PR.

The checked-in artifact is the sampler and the method page:
[Suggested-Prompt Survey](../../docs/suggested-prompt-survey.md).
